# PicoPDF Privacy Policy

Bilingual English/Turkish privacy policy for the PicoPDF Android application
(`com.mustafaoguzbaran.picopdf`). The canonical GitHub Pages URL is:

https://mustafaoguzbaran.github.io/picopdf-privacy/

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run export:pages
npm test
npm run lint
```

`npm run export:pages` renders the maintained React policy into the root
`index.html` used by GitHub Pages. Commit the generated file whenever the policy
content or styles change.
